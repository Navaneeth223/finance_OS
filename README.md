# 💰 finance_OS — AI-Powered Personal Finance OS

> Smart budgeting, GPT-4o transaction insights, real-time analytics, and a beautiful dashboard. Built with Next.js 14, TypeScript, and Prisma.

finance_OS is an AI-powered personal finance OS: categorize transactions automatically, get GPT-4o insights, and visualize spending in real time.

🌐 **Live demo:** https://finance-os-dun.vercel.app

---

## ✨ Features

- 🧠 **GPT-4o insights** — natural-language transaction analysis
- 📊 **Real-time analytics** — spending by category, trends
- 💡 **Smart budgeting** — auto-categorization + alerts
- 🎨 **Beautiful dashboard** — Next.js 14 + Tailwind
- 🔒 **Local-first data** via Prisma

## 🛠 Tech Stack

| Layer | Tech |
|---|---|
| Framework | Next.js 14 (App Router), TypeScript |
| ORM | Prisma |
| AI | OpenAI GPT-4o |
| UI | Tailwind CSS |
| Deploy | Vercel |
